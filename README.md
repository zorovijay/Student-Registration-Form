# Student Registration Form

## Project Overview
The Student Registration Form is a simple web-based application developed using HTML, CSS, and JavaScript. It allows users to enter student details and dynamically display them in a table.

## Features
- Add student details such as Name, Age, Gender, Course, and Email.
- Display submitted student details in a table.
- Delete student records.
- Simple and user-friendly interface.
- Dynamic table updates using JavaScript DOM manipulation.

## Technologies Used
- **HTML5** – Structure of the application.
- **CSS3** – Styling and layout.
- **JavaScript** – Form handling and DOM manipulation.

## How to Run the Project
1. Clone this repository:
   ```bash
   git clone https://github.com/zorovijay/Student-Registration-Form.git
   ```
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter student details and click the Save button.
5. Use the Delete button to remove a student record.
